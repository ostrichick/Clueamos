# Clueamos (클루아모스)

> **부부가 함께 즐기는 4인 추리 웹 보드게임 (사람 2명 + 성격이 다른 AI 탐정 2명)**  
> Clue의 핵심 재미(추리, 정보 수집, 블러핑)를 바탕으로, 독자적인 세계관과 페어 플레이 메커니즘을 갖춘 웹앱 프로젝트입니다.

---

## 📌 핵심 프로젝트 개요

* **플레이 인원:** 총 4명 (사람 2명 + 컴퓨터 AI 탐정 2명)
* **주요 타깃/사용자:** 부부(2인)가 한 기기(Pass-and-play) 또는 로컬 네트워크/웹에서 즐겁게 플레이할 수 있는 추리 게임
* **플레이 모드:** **반협력형(Semi-cooperative)** 또는 **협력/경쟁 선택형**
  * 두 사람이 함께 사건을 해결해 나가면서도 개인 점수/목표로 소소한 경쟁의 재미 유지
* **핵심 차별점:**
  * **정답을 모르는 공정한 AI:** AI가 정답을 미리 알고 부정행위를 하지 않으며, 사람과 동일한 정보(손패 + 공개된 질문/답변 기록)만을 바탕으로 논리적/직감적으로 추론
  * **성격이 다른 AI 2인:**
    * `AI 1 (논리형 탐정)`: 획득한 단서를 정직하고 체계적으로 소거하며 높은 확신 시 최종 추리
    * `AI 2 (직감/블러핑형 탐정)`: 공격적이고 과감한 추리, 특정 인물 집중 의심, 블러핑 시도
  * **추리 차원 확장:** 범인 + 장소 + 도구 외에 **'범행 동기'** 요소 추가 (4대 요소)
  * **자동 추리 노트 (Deduction Sheet):** 손으로 적을 필요 없이 UI 상에서 질문/답변 및 소거법이 직관적으로 기록되는 편의성

## 🏰 기본 시나리오 & 세계관 (MVP)

### 콘셉트: "폭풍우 치는 밤의 고립된 호텔 (The Grand Velvet Hotel)"
* **인물 (6명):** 호텔 지배인, 전직 군인 투숙객, 미식가 요리사, 야간 경비원, 무명 여배우, 수상한 의사
* **장소 (6곳):** 연회장, 서재, 주방, 지하 와인창고, 옥상 정원, 객실 304호
* **도구 (6개):** 은제 촛대, 빈 독약병, 마스터 키, 빈티지 밧줄, 날카로운 만년필, 무거운 트로피
* **동기 (4개):** 거액의 유산 상속, 치명적인 비밀 폭로, 원한과 복수, 희귀 보석 절도

## 🛠 추천 기술 스택

AI 교체 및 유지보수, 빠른 웹 프로토타입 구현을 위해 검증된 모던 웹 스택을 권장합니다.

* **Frontend:** Next.js (React) + TypeScript + Tailwind CSS
* **상태 관리:** Zustand (게임 엔진 로직과 UI 분리)
* **아이콘 & 애니메이션:** Lucide React, Framer Motion (부드러운 카드 턴 및 주사위/이동 애니메이션)
* **게임 엔진:** 순수 TypeScript 기반 순수 함수형 엔진 (UI 종속성 제로)

---

## 🧩 게임 엔진 아키텍처

게임 로직과 화면 UI는 완전히 분리되어 작동합니다.

```
src/
├── engine/                # UI와 무관한 순수 게임 엔진 (TDD로 검증 가능)
│   ├── types.ts           # GameState, Player, Card, Action 등 타입 정의
│   ├── state.ts           # 게임 초기화 및 불변 상태 전이 함수
│   ├── rules.ts           # 질문, 증거 제시, 최종 추리 판정 로직
│   └── ai/
│       ├── aiBase.ts      # AI 공통 인터페이스 (GameState -> Action)
│       ├── logicAI.ts     # 논리 소거형 AI 탐정
│       └── instinctAI.ts  # 직감 & 블러핑형 AI 탐정
├── components/            # React UI 컴포넌트
│   ├── board/             # 호텔 맵 및 말 이동
│   ├── sheet/             # 자동 추리 노트 (체크리스트)
│   ├── dialogue/          # 질문 및 증거 제시 팝업
│   └── hud/               # 턴 표시기, 로그 창, 플레이어 상태
└── pages/ or app/
```
